# SSH Manager для Linux

Нативное приложение на GTK с терминалом VTE и двухпанельным SFTP. Поддерживает рабочие столы Wayland и X11 через GTK.

## Установка

Скачайте пакет или архив со [страницы релиза для Linux](https://github.com/Clarkufa/sshmanager/releases/latest).

На Debian и Ubuntu откройте папку с пакетом и установите его.

```sh
sudo apt install ./SSH-Manager-Linux.deb
```

На Fedora скачайте `SSH-Manager-Linux.rpm` и установите его через DNF.

```sh
sudo dnf install ./SSH-Manager-Linux.rpm
```

После установки SSH Manager появится в меню приложений. Из терминала он запускается командой `ssh-manager`.

На других дистрибутивах распакуйте архив `SSH-Manager-Linux.tar.gz` и запустите `./ssh-manager`. Нужны Python 3.10+, PyGObject, GTK 3, VTE 2.91 (типовые пакеты GTK GIR / typelib), Paramiko, Cryptography и OpenSSH. Для сохранения паролей требуется работающий Secret Service, например GNOME Keyring, и команда `secret-tool`.

Для RDP нужен клиент FreeRDP. DEB и RPM указывают FreeRDP как рекомендуемый пакет. APT и DNF устанавливают его по умолчанию, если пакет доступен в подключённых репозиториях. Для архива TAR.GZ или при отключённой установке рекомендуемых пакетов установите FreeRDP вручную.

## Обновления

Начиная с 1.8.5 приложение проверяет релизы при запуске. Кнопка **Обновления** позволяет проверить версию и подтвердить установку. Установленные пакеты обновляются через APT для DEB и через DNF для RPM. Система может запросить права администратора через `pkexec`. Для версии из TAR.GZ приложение заменяет исходную папку из архива после проверки её файлов. При необходимости ручной установки оно предложит открыть папку с проверенным файлом.

## Подключения и файлы

- Каталог читает и редактирует `~/.ssh/config`. На отдельные обычные псевдонимы можно назначить вкладки и сохранить ключи. Дополнительные директивы профиля остаются в конфиге.
- Кнопка «Подключиться» открывает вкладку встроенного терминала. В «Сеансах» можно открыть несколько терминалов и менять их порядок.
- `Shift+Esc` возвращает к списку серверов и оставляет сеанс открытым. `Esc` передаёт Escape в терминал.
- В терминале `Ctrl+Shift+C` и `Ctrl+Insert` копируют выделение. `Ctrl+C` копирует выделенный текст, а без выделения прерывает удалённую команду. Вставка работает через `Ctrl+V`, `Ctrl+Shift+V`, `Shift+Insert` и правую кнопку мыши. `Ctrl+Shift+A` выделяет текст терминала. Для вставки текста с переносами строк потребуется подтверждение.
- Кнопка «Файлы» в каталоге и в терминале открывает отдельное окно SFTP. Для загрузки можно выбрать локальные файлы или перетащить их из файлового менеджера на правую панель.
- Поле «Пароль SSH» сохраняет пароль в системном хранилище для конкретного адреса, порта и пользователя. Данные приложения хранятся в `${XDG_CONFIG_HOME:-~/.config}/ssh-manager`.
- Защищённый архив Linux-версии включает конфиг, настройки, ключи из каталога конфига и сохранённые пароли SSH, RDP и VNC. Обычный ZIP включает конфиг, настройки и ключи.

## Удалённый рабочий стол (RDP)

Во вкладке **RDP** добавьте профиль или импортируйте файл `.rdp`. Пароль из поля **Пароль** хранится в Secret Service отдельно для каждого профиля, в том числе для одного IP с разными портами. Если пароль не сохранён, перед подключением появится окно **Вход**. SSH Manager явно передаёт FreeRDP пользователя, домен и пароль профиля: FreeRDP 3 получает их через переменную окружения процесса, а FreeRDP 2 скрывает пароль в списке процессов сразу после запуска.

- На X11 и в XWayland рабочий стол открывается внутри окна SSH Manager в разделе **Сеансы**, а разрешение подстраивается под размер окна. **Весь экран** разворачивает сеанс на весь монитор, **В окне** переоткрывает его в отдельном окне FreeRDP.
- На чистом Wayland FreeRDP открывается в отдельном окне, а сеанс остаётся в списке **Сеансы** со статусом.
- После отключения показывается причина и кнопки **Переподключить** и **Закрыть сеанс**.
- В разделе **Дополнительно** окна профиля можно подключить локальные папки, принтеры, все мониторы (в отдельном окне) и шлюз RD Gateway.

## Удалённый рабочий стол (VNC)

Во вкладке **VNC** добавьте профиль или введите `vnc://host:5900` в поле быстрого подключения. Рабочий стол открывается в разделе **Сеансы** на X11 и Wayland. Для VNC установите `gir1.2-gtk-vnc-2.0` на Debian/Ubuntu или `gtk-vnc2` на Fedora. Эти пакеты указаны как рекомендуемые в DEB и RPM. Поле **Через SSH-сервер** включает туннель, пароль VNC хранится в Secret Service.

## Новое в версии 1.10

- **Быстрое подключение** в строке инструментов: `user@host:port` или `rdp://host`, затем приложение предложит сохранить профиль.
- **В избранное** в меню сервера и вкладка **Избранное**, раздел **Недавние** в окне **Новый сеанс**.
- В окне сервера: **Через сервер (ProxyJump)**, **Пробросы портов** (L, R, D) и **Создать ключ…**. Пункт **Скопировать ключ на сервер** в меню сервера добавляет публичный ключ в `~/.ssh/authorized_keys`.
- После обрыва SSH — строка с кнопками **Переподключить** и **Закрыть сеанс**, автоматическое переподключение включается в **Настройках**.
- Кнопка **Команды** в сеансе отправляет сохранённые команды в текущий или во все открытые сеансы.
- **Настройки**: шрифт и размер терминала, прокрутка, пользователь и порт по умолчанию, переподключение, сворачивание в трей, проверка обновлений.
- **Резервные копии** → **Импорт из других программ…**: PuTTY (`~/.putty/sessions`), mRemoteNG и MobaXterm.
