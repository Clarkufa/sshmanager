# SSH Manager для macOS

Универсальная сборка для macOS 14 Sonoma и новее. Один DMG содержит приложение для Mac с Apple Silicon (arm64) и Intel (x86_64).

[Скачать DMG](https://github.com/Clarkufa/sshmanager/releases/latest/download/SSH-Manager-macOS.dmg) · [Релизы проекта](https://github.com/Clarkufa/sshmanager/releases)

Откройте DMG и перетащите **SSH Manager** в **Программы**. У опубликованной сборки локальная подпись ad hoc. При первом запуске Gatekeeper может потребовать ручного подтверждения. [Справка Apple по запуску приложений](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unidentified-developer-mh40616/mac).

## Обновления

Начиная с 1.8.5 приложение проверяет релизы при запуске. Проверку можно запустить из меню **Подключения → Проверить обновления…**. Перед установкой приложение сверяет SHA‑256 и просит подтверждение. Если macOS запретит замену или запуск приложения, окно обновления предложит открыть проверенный DMG.

## Подключения и файлы

- Серверы читаются из `~/.ssh/config`. Каталог показывает секции `Host` с одним псевдонимом. Системный OpenSSH применяет `Include`, шаблоны и `Match` при подключении. Перед изменением конфига приложение сохраняет прежнюю версию в `~/.ssh/config.bak`.
- Можно создавать цветные вкладки, искать серверы по имени и адресу и открывать несколько встроенных терминалов. `⌘N` открывает выбор сервера, `⌘F` фокусирует поиск по каталогу, `⌃⇥` переключает последние сеансы. В терминале `⌘C` копирует выделение, `⌘A` выделяет весь текст, а `⌘V` и правая кнопка мыши вставляют текст. Для вставки текста с переносами строк потребуется подтверждение.
- `Shift+Esc` возвращает к списку серверов и оставляет сеанс открытым. `Esc` передаёт Escape в терминал.
- Если проброс порта мешает открыть терминал, откройте меню сеанса `⋯` и выберите **Новый сеанс без проброса портов**.
- Для сохранения пароля укажите SSH-пользователя и адрес без шаблонов. Пароль хранится в Связке ключей macOS. При входе SSH Manager может запросить подтверждение ключа сервера, код или парольную фразу ключа.
- В двухпанельном окне SFTP можно передавать файлы и папки, загружать объекты перетаскиванием из Finder, выбирать поведение при совпадении имён и создавать, переименовывать или удалять файлы и пустые папки на сервере. SFTP использует отдельное соединение с тем же профилем OpenSSH без проброса портов.
- Вкладки и тема сохраняются в `~/Library/Application Support/SSH Manager/tabs.xml`. Копии ZIP и защищённые `.sshbackup` используют формат Windows-версии. Защищённый архив может включать пароли. Перед импортом приложение показывает заменяемые файлы и сохраняет их прежние версии в `~/.ssh/.ssh-manager-restore`.

## Удалённый рабочий стол (RDP)

Для подключения по RDP установите FreeRDP (`brew install freerdp`) или Microsoft Windows App из Mac App Store. Для SSH и SFTP достаточно приложения из DMG и системных компонентов macOS. [Инструкция Microsoft по установке Windows App](https://learn.microsoft.com/en-us/windows-app/get-started-connect-devices-desktops-apps?pivots=remote-pc)

Во вкладке **RDP** добавьте профиль или импортируйте файл `.rdp`. Пароль из поля **Пароль** хранится в Связке ключей отдельно для каждого профиля, в том числе для одного IP с разными портами. Если найден FreeRDP, кнопка **Подключиться** запускает его и явно передаёт пользователя, домен и пароль профиля. Если пароль не сохранён, приложение спросит его перед подключением. Без FreeRDP рабочий стол открывается в Windows App. Он не принимает пароль из файла `.rdp`, поэтому SSH Manager на минуту копирует сохранённый пароль в буфер обмена для вставки в окно входа. SSH-сеансы остаются открытыми в SSH Manager. Сортировка по названию и IP сохраняется отдельно для каждой группы и протокола.
