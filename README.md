# SSH Manager

Нативный менеджер SSH и SFTP для Windows 10 версии 1809 и новее и Windows 11. Сохраняйте серверы по вкладкам, переключайтесь между терминалами и копируйте файлы в двухпанельном окне.

## Скачать

[Установщик MSI](https://github.com/Clarkufa/sshmanager/releases/latest/download/SshManagerSetup.msi) · [Переносной EXE](https://github.com/Clarkufa/sshmanager/releases/latest/download/SshManager.exe) · [Все релизы](https://github.com/Clarkufa/sshmanager/releases)

Начиная с версии 1.8.0 приложение проверяет наличие новой стабильной версии при запуске. В каталоге также есть кнопка «Обновления». После скачивания проверяется SHA‑256 из GitHub Releases, затем менеджер запрашивает подтверждение установки и перезапуска. Установленная версия обновляется через Windows Installer, переносная заменяет свой EXE.

## Подключения и вкладки

- «Добавить сервер» открывает форму с псевдонимом, адресом, SSH-пользователем, портом и ключами. Доступные ключи подбираются из папки `.ssh`. Через «Обзор» можно выбрать файл в другой папке.
- В поле «Пароль» можно задать пароль для SSH-пользователя. При открытии нового сеанса приложение подставит его на запрос OpenSSH. Вход использует адрес, порт и пользователя из карточки. Пустое поле при редактировании сохраняет прежний пароль, если эти три поля совпадают. Чтобы стереть его, отметьте «Удалить пароль». Подтверждение ключа нового сервера и одноразовые коды вводятся вручную. Для автоматического ввода пароля требуется OpenSSH 8.4 или новее.
- «Подключиться» открывает встроенный SSH-сеанс. Если для этого псевдонима уже есть открытый сеанс, кнопка «К сеансу» возвращает в последний использованный. В меню сервера есть команды «Новый сеанс» и «Открыть в Windows Terminal».
- В разделе «Сеансы» видны псевдоним, адрес и открытые консоли. Поиск учитывает имя сеанса, адрес и группу. `Ctrl+Tab` переключает между двумя последними открытыми сеансами, `Ctrl+Shift+P` фокусирует поиск. Правый клик по сеансу позволяет задать ему метку, открыть ещё один или закрыть его.
- «Новый сеанс» открывает окно выбора сервера с поиском. «Новый сеанс этого сервера» открывает ещё одну консоль для выбранного сервера. Клик по строке открытого сеанса переносит ввод в терминал. При ошибке локального проброса в меню сеанса появляется команда «Новый сеанс без проброса портов».
- В консоли `Ctrl+Shift+C` копирует выделение, `Ctrl+Shift+V` вставляет текст, а колесо мыши или `Shift+Page Up/Down` прокручивает вывод. Возврат к списку серверов и сворачивание в трей сохраняют сеансы. Команда «Выход» завершает встроенные сеансы.
- Создайте вкладку кнопкой «Новая вкладка». Чтобы назначить сервер, в его меню выберите «Переместить во вкладку». Один сервер может быть в одной пользовательской вкладке и всегда отображается в разделе «Все серверы». Правый клик по вкладке позволяет её переименовать, выбрать или убрать цветовую метку и удалить вкладку.
- Перетаскивайте пользовательские вкладки или меняйте их порядок через меню вкладки. Команда «Открывать при запуске» задаёт начальную вкладку. Можно выбрать любую вкладку, включая закреплённую слева «Все серверы».
- Кнопка «Тёмная тема» переключает оформление в каталоге и в разделе «Сеансы». Выбор сохраняется после перезапуска и при экспорте настроек.
- При сворачивании или закрытии окна приложение остаётся в трее. Нажмите на значок или запустите SSH Manager повторно, чтобы открыть то же окно. Для завершения работы выберите «Выход» в меню значка.

## Файлы

Кнопка «Файлы» есть в строке сервера и в разделе «Сеансы». Она открывает двухпанельное окно SFTP с файлами компьютера слева и сервера справа. Чтобы открыть папку, дважды нажмите на неё или введите путь. Выберите файлы или папки и нажмите «На сервер» или «На компьютер». Для загрузки можно также перетащить файлы из левой панели или из Проводника на правую панель.

Окно показывает прогресс передачи и позволяет отменить очередь. При совпадении имён можно сохранить оба файла, пропустить элемент или заменить файл. В правой панели можно создавать папки, переименовывать элементы и удалять файлы или пустые каталоги. Ссылки пропускаются при копировании папок.

SFTP использует настройки того же профиля OpenSSH, сохранённый пароль и отдельное подключение без проброса портов. Открытый SSH-сеанс для обмена файлами не требуется.

## Файлы настроек

- Подключения читаются из `%USERPROFILE%\.ssh\config` в UTF‑8. В списке показываются секции `Host` с одним обычным псевдонимом. Секции с несколькими псевдонимами, шаблоны, `Match` и файлы `Include` редактируются в OpenSSH config вручную. Пустые поля в форме используют остальные настройки OpenSSH.
- При изменении существующего файла предыдущая версия сохраняется в `%USERPROFILE%\.ssh\config.bak`. Ключи читаются только для определения формата, а в конфиг записывается путь к выбранному файлу.
- Тема и вкладки хранятся отдельно от OpenSSH в `%LOCALAPPDATA%\SSH Manager\tabs.xml`. Серверы во вкладках привязаны к псевдонимам из `config`.
- Сохранённые SSH-пароли хранятся в Диспетчере учётных данных Windows для текущего пользователя.

## Резервные копии

Кнопка «Резервные копии» экспортирует и импортирует конфиг OpenSSH, настройки вкладок и файлы SSH-ключей. Защищённый архив `.sshbackup` включает сохранённые SSH-пароли и открывается в SSH Manager с паролем от архива. При импорте SSH-пароли записываются в Диспетчер учётных данных Windows на этом ПК. Обычный `.zip` содержит конфиг, настройки и ключи в открытом виде.

При экспорте сохраняются доступные локальные ключи, поддерживаемые ссылки `IdentityFile` и `CertificateFile`, а также файлы `Include` с буквальными путями или шаблоном `*`/`?` в имени. Пути к сохранённым файлам переписываются относительно `~/.ssh` внутри архивного конфига. Для пропущенных ссылок приложение показывает количество после экспорта. Файлы `authorized_keys` и `known_hosts` не входят в копию.

При импорте приложение показывает изменяемые файлы и сохраняет предыдущие версии в папках `.ssh-manager-restore` внутри `.ssh` и папки настроек менеджера.

## Сборка

В PowerShell выполните `./build.ps1`. Понадобятся .NET SDK и Windows Python 3.12. `./build.ps1 -AppOnly` собирает один EXE без Python. По умолчанию результаты находятся в `build/release`. Параметр `-OutputDirectory` позволяет собрать новую версию в отдельную папку, пока работает предыдущая.

Встроенный терминал использует WinForms, Windows ConPTY и [VtNetCore](third_party/VtNetCore-LICENSE.txt). Исходники библиотеки закреплены архивом из коммита `4e723ac24e42316e533e6aa4c427ab5273077214` и компилируются вместе с приложением. При сборке парсер OSC дополняется поддержкой завершителя `ESC \`.

## Публикация релиза

Обновите версию в `src/AssemblyInfo.cs` и `installer/app.manifest`, затем отправьте коммит в GitHub. Войдите через GitHub CLI и запустите `./publish.ps1 -NotesFile путь-к-описанию.md`. Скрипт соберёт MSI и EXE, сверит версию и опубликует оба файла в GitHub Releases с тегом этой версии.
