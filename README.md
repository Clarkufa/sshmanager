# SSH Manager

SSH Manager управляет подключениями по **SSH** и **RDP**. Открывайте SSH-терминалы и удалённые рабочие столы, группируйте серверы и передавайте файлы по SFTP.

## Скачать

Выберите файл для своей системы. Все загрузки также доступны на [странице последнего релиза](https://github.com/Clarkufa/sshmanager/releases/latest).

### Windows 10 (1809 и новее) и Windows 11

- **MSI** для обычной установки. [Скачать установщик](https://github.com/Clarkufa/sshmanager/releases/latest/download/SshManagerSetup.msi)
- **EXE** для запуска без установки. [Скачать переносную версию](https://github.com/Clarkufa/sshmanager/releases/latest/download/SshManager.exe)

### macOS 14 Sonoma и новее

Один DMG подходит для Mac с Apple Silicon (серия M) и Intel. Откройте образ и перетащите **SSH Manager** в папку **Программы**. Сборка выпущена без нотаризации Apple, поэтому при первом запуске macOS может запросить подтверждение. [Скачать DMG](https://github.com/Clarkufa/sshmanager/releases/latest/download/SSH-Manager-macOS.dmg) · [Инструкция для macOS](macos/README.md)

### Linux

- **Debian и Ubuntu.** Скачайте пакет DEB и откройте его в менеджере пакетов или установите через `apt`. [Скачать DEB](https://github.com/Clarkufa/sshmanager/releases/latest/download/SSH-Manager-Linux.deb)
- **Fedora.** Скачайте пакет RPM и установите через `sudo dnf install ./SSH-Manager-Linux.rpm`. [Скачать RPM](https://github.com/Clarkufa/sshmanager/releases/latest/download/SSH-Manager-Linux.rpm)
- **Другие дистрибутивы.** Распакуйте архив, установите зависимости и запустите `./ssh-manager`. [Скачать TAR.GZ](https://github.com/Clarkufa/sshmanager/releases/latest/download/SSH-Manager-Linux.tar.gz) · [Инструкция и зависимости для Linux](linux/README.md)

## Первое подключение по SSH

1. Запустите SSH Manager. Если у вас уже есть настройки OpenSSH, приложение покажет подключения из файла `.ssh/config` в вашей домашней папке.
2. Чтобы добавить новое подключение, нажмите **Добавить сервер**. Введите удобное имя латиницей, например `work-server`, адрес сервера и имя SSH-пользователя. Укажите порт, если сервер использует порт, отличный от стандартного `22`.
3. Если для входа используется ключ, выберите его в карточке сервера. Нажмите **Сохранить**, затем **Подключиться**. Терминал откроется внутри приложения.

## Удалённый рабочий стол (RDP)

На Windows откройте вкладку **RDP** и нажмите **Добавить сервер**. Укажите название, адрес и пользователя или импортируйте готовый файл `.rdp`. В настройках профиля можно задать порт, домен, разрешение экрана, полноэкранный режим и общий буфер обмена.

Вкладки **SSH** и **RDP** показывают отдельные списки. Переключение между ними сохраняет открытые подключения. В разделе **Сеансы** можно вернуться к любому открытому терминалу или удалённому рабочему столу. Чтобы отсортировать текущую группу на Windows, нажмите заголовок **Псевдоним** / **Название** или **Адрес**. IP-адреса сортируются численно, а порядок сохраняется отдельно для каждой группы и протокола.

Встроенные RDP-сеансы доступны на Windows с версии **1.9.0**. [Скачать релиз](https://github.com/Clarkufa/sshmanager/releases/tag/v1.9.0)

## Что можно делать

- **Держать открытыми несколько терминалов.** Переключайтесь между серверами и открывайте несколько сеансов к одному серверу.
- **Группировать серверы.** Создавайте вкладки, например для работы, личных проектов или тестовых серверов. Ищите подключения по имени и адресу.
- **Передавать файлы.** Нажмите **Файлы** рядом с сервером. Слева будут файлы компьютера, справа — сервера. Выберите, что скопировать и в какую сторону. Передача работает по SFTP даже без открытого терминала.
- **Делать резервные копии.** Экспортируйте подключения, вкладки и SSH-ключи. Защищённый архив может включать сохранённые пароли. Перед переносом на другую систему проверьте поддерживаемые форматы в инструкции для своей платформы.
