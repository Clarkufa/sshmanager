## SSH Manager 1.17.1

- Windows: русский текст в буфере обмена VNC больше не искажается на серверах без расширенного буфера обмена (TightVNC, старые UltraVNC, x11vnc). Текст от сервера читается как UTF-8 или в кодировке Windows (cp1251), а текст с кириллицей уходит на сервер в cp1251.
- Windows: текст из расширенного буфера обмена (UltraVNC, TigerVNC) теперь читается правильно при любом способе завершения сжатых данных.
- Буфер обмена RDP проверен с кириллицей и эмодзи в обе стороны.
- Версии для macOS и Linux пересобраны с номером 1.17.1 без изменений.
