# Спецификация интерфейса SSH Manager

Единый образец для всех трёх версий. Источник — Windows-версия (`src/`). Linux (`linux/ssh_manager/`) и macOS (`macos/Sources/`) повторяют раскладку, подписи, порядок пунктов меню, тексты и поведение; отличия допускаются только там, где их требует платформа (шрифты, системные диалоги выбора файлов, стандартные сочетания ⌘ на macOS вместо Ctrl).

Размеры — логические пиксели при 96 DPI. Подписи даны точно, их нельзя перефразировать.

## 2. Главное окно

Одно рабочее окно. Под шапкой три колонки: «Серверы», «Сеансы» и рабочая область. В рабочей области показывается таблица каталога, активный сеанс или «Файлы». При смене области открытые подключения и передачи файлов продолжают работать. При запуске в рабочей области открыта таблица каталога.

Заголовок окна: `SSH Manager X.Y.Z`. Размер 1280×720, минимум 800×480, по центру экрана.

### 2.1 Шапка (54)
Слева направо: логотип 32×32; «SSH Manager» (шрифт акцента); поле «Быстрое подключение» по центру свободного места (ширина до 460, высота 32, подсказка «Быстрое подключение: user@host, rdp:// или vnc://»); справа кнопки:
1. «Серверы» — Outline, 94, иконка Server. Показывает или скрывает колонку «Серверы».
2. «Сеансы» — Outline, 116, иконка Terminal. Показывает или скрывает колонку «Сеансы». При открытых сеансах — «Сеансы · N».
3. «Настройки» — Quiet, 118, иконка Settings.
4. Тема — Outline, 130.
5. «Добавить сервер» — Primary, 158, иконка Plus. Открывает диалог протокола, выбранного в таблице каталога.

Если кнопкам не хватает места, подписи убираются по очереди: «Настройки», тема, «Серверы», «Сеансы»; остаются значки.

Клавиши: Ctrl+F — поиск в таблице каталога, если она открыта, иначе поиск в колонке «Серверы»; Ctrl+N — «Добавить сервер»; Ctrl+L или Ctrl+K — быстрое подключение; F5 — «Обновить» (в таблице каталога); Shift+Esc — таблица каталога; Ctrl+Tab — предыдущий сеанс; Ctrl+Shift+P — поиск сеанса. Пока фокус в терминале или на удалённом рабочем столе, Ctrl+F, Ctrl+N, Ctrl+L и Ctrl+K получает сеанс. macOS: ⌘F — то же, что Ctrl+F; ⌘L — быстрое подключение; ⇧⌘N — «Добавить сервер»; ⌘N — «Новый сеанс…»; ⇧Esc — таблица каталога; ⌃Tab — предыдущий сеанс; ⇧⌘P — поиск сеанса. В меню «Подключения» также есть «Колонка «Серверы»» и «Колонка «Сеансы»».

### 2.2 Колонки
- «Серверы» — 248, «Сеансы» — 203, рабочая область занимает остальное.
- Если рабочей области остаётся меньше 620 для таблицы каталога или меньше 460 для сеанса и файлов, колонки сворачиваются сами: сначала «Серверы», затем «Сеансы». На широком окне они возвращаются.
- Кнопки «Серверы» и «Сеансы» в шапке показывают колонку даже на узком окне. Скрытая кнопкой колонка не появляется сама, пока её не покажут снова.
- Колонка «Серверы»: заголовок «Серверы» и кнопка «Каталог» (Quiet, 88, Server) — открывает таблицу каталога в рабочей области. Ниже переключатель «SSH», «RDP», «VNC» (по 62), поиск «Найти сервер», список, строка «Серверов: N» и «Подключиться» (Primary, 128).
- Список сгруппирован по вкладкам каталога: «Недавние» (до 5, с точкой цвета вкладки), затем вкладки в порядке каталога (точка цвета вкладки, название, справа число серверов), затем «Без вкладки». Если ни один сервер не во вкладке, вместо «Без вкладки» — «Все серверы». Пустые вкладки не показываются. При поиске список плоский, без групп.
- Заголовок группы (▾ развёрнута, ▸ свёрнута) сворачивается и разворачивается щелчком, пробелом, Enter или стрелками ←/→. Свёрнутые группы сохраняются: в `tabs.xml` атрибут корня `collapsed` — через пробел id вкладок, `ungrouped` и `recent`; в `settings.json` (Linux) — список `"collapsed"` с теми же значениями. Удалённые вкладки из списка выпадают.
- Строка сервера: имя (★ у избранного), ниже адрес и «сеансов: N», если сеансы открыты. Двойной щелчок, Enter или «Подключиться» возвращают в открытый сеанс сервера либо открывают новый.
- Правая кнопка, клавиша меню или Shift+F10 на строке открывают то же меню, что в таблице каталога (§2.7, §2.8, меню VNC в §8): «Подключиться», «Новый сеанс», «Файлы (SFTP)», «Изменить», «Переместить во вкладку», избранное, «Удалить» и остальное. На заголовке группы — «Свернуть» / «Развернуть». Delete на строке — «Удалить».

### 2.2.1 Переключатель протокола таблицы (39)
Три кнопки «SSH» (Terminal), «RDP» (Server) и «VNC» (Server), по 86. Активная — SelectedTab. Переключение меняет первый столбец («Псевдоним» ↔ «Название»), столбец действия («Терминал» ↔ «Рабочий стол»), скрывает столбец SFTP у RDP и VNC, меняет путь в подвале и очищает поиск.

### 2.3 Полоса вкладок (49)
Горизонтальная прокрутка без переноса, справа кнопка «Новая вкладка» (Quiet, 140, Plus).
- Первая вкладка всегда «Все серверы», её нельзя перетащить.
- Вкладка: высота 30, промежуток 5, шрифт акцента; при цветовой метке перед текстом точка 11 px; максимальная ширина 250. Выбранная — SelectedTab, остальные — Tab.
- Перетаскивание меняет порядок; место вставки показывает вертикальная линия Teal 2 px; у края полоса прокручивается.
- Меню вкладки (правая кнопка, клавиша меню, Shift+F10):
  1. «Переименовать вкладку»
  2. «Цветовая метка» → «Без метки», затем 7 цветов (с точкой; текущий отмечен)
  3. «Переместить влево» (недоступно у первой)
  4. «Переместить вправо» (недоступно у последней)
  5. «Открывать при запуске» (отмечено, если это стартовая вкладка)
  6. разделитель
  7. «Удалить вкладку» (красный)
  У «Все серверы» есть только «Открывать при запуске».
- Подтверждение удаления: «Удалить вкладку «X»? Её подключения будут доступны во вкладке «Все серверы».» — Да/Нет, по умолчанию Нет.
- Название: 1–32 символа, без управляющих символов, не «Все серверы» и не «Без вкладки», уникальное без учёта регистра. Ошибки: «Введите название вкладки длиной от 1 до 32 символов.» / «Это название уже используется. Выберите другое.»
- Новый сервер, созданный при открытой вкладке, попадает в неё.
- При запуске открывается стартовая вкладка.

### 2.4 Строка инструментов (46)
- Слева поиск 265×34 с лупой и подсказкой «Найти сервер». Фильтрует при вводе, без учёта регистра: SSH — псевдоним, хост, пользователь, вкладка; RDP — название, адрес, учётная запись, вкладка.
- Справа, Quiet:
  1. «Резервные копии» (Folder) → меню «Экспорт архива…» (Copy), «Импорт архива…» (Folder)
  2. «Обновить» (Refresh) — перечитать конфиг и настройки
  3. «Изменить» (Edit)
  4. «Удалить» (Delete, красный)
  «Изменить» и «Удалить» доступны только при выбранной строке.

Рамка 1 px Line. Заголовок 37 (фон Canvas, текст Muted), строки 45, только горизонтальные линии, выделение всей строки.

| Столбец | Содержимое |

| «Адрес» | хост |

| «Порт» | |

- «Таблетка»: фон Mint, радиус 7, иконка и текст Teal (Folder для файлов, Terminal для подключения).
- Сортировка только по первым двум столбцам, подсказка заголовка «Нажмите для сортировки». Клик по кругу: по возрастанию → по убыванию → исходный порядок. Сохраняется для каждой вкладки и протокола.   - «Добавьте сервер или перенесите сюда подключение из «Все серверы».» — пустая вкладка
  - «Добавьте RDP-подключение или импортируйте профиль .rdp.» — RDP

### 2.6 Подвал (47)

Справа кнопка обновлений (Outline, 170, Refresh): «Обновления» / «Проверка…» / «Загрузка · N%» / «Обновить до X.Y.Z». Когда в рабочей области сеанс или «Файлы», путь и счётчик скрыты, кнопка остаётся.

## 3. Сеансы

Колонка «Сеансы» стоит между колонкой «Серверы» и рабочей областью (§2.2).

### 3.1 Управление
Заголовок колонки «Сеансы» и кнопка «+» (Quiet, 34, Plus, подсказка «Новый сеанс») — открывает выбор сервера. Щелчок или Enter по сеансу открывает его в рабочей области, даже если там была таблица каталога или «Файлы».

### 3.2 Панель сеансов
- Поиск «Найти сеанс»; Enter открывает выбранный или первый сеанс.
- «Открыто: N» (Muted); если часть сеансов завершена — «Открыто: N из M».
- Список, строка 46, рамка 1 px Line. Строка: точка 7×7 цвета вкладки (Teal без вкладки; Line у завершённого); заголовок шрифтом акцента; подзаголовок Muted: `SSH · user@host:port` / `RDP · host:port`, у завершённого — `SSH · Сеанс завершён`.
- Заголовок сеанса: `псевдоним`; второй и следующие сеансы того же сервера — `псевдоним · N`; после переименования — `псевдоним · метка`.
- Поиск по заголовку, адресу, вкладке и протоколу.

### 3.2.1 Открытые файлы
- Пока открыта хотя бы одна панель «Файлы», под списком сеансов есть раздел «Открытые файлы» (шрифт акцента) и список до 4 строк по 46.
- Строка: точка цвета вкладки, имя сервера, ниже Muted «Файлы», после подключения «Файлы · SFTP» или «Файлы · TightVNC».
- Щелчок или Enter открывают панель в рабочей области. Меню: «Открыть», «Закрыть файлы». Delete закрывает панель.
- «Файлы» у сервера, у которого панель уже открыта, переходят к ней.
- Панель «Файлы» в рабочей области: заголовок «Файлы · сервер» шрифтом акцента, «Переподключить» и «Закрыть» (Quiet, красная). Передача продолжается, пока показан другой сеанс. После закрытия рабочая область возвращается к активному сеансу, без сеансов — к таблице каталога.

### 3.3 Информационная строка (65)
- Заголовок (акцент): название сеанса или «Сеансы SSH, RDP и VNC», если сеанса нет.
- Строка деталей (Muted), части через «  ·  »: протокол, адрес, вкладка; затем «ошибка проброса порта» или «без проброса»; затем статус. Статусы SSH: «завершён»; RDP: «подключение», «подключён», «отключён», «отключён (код N)», «ошибка подключения».
- Кнопки по порядку:

| Кнопка | Стиль | Для |
|---|---|---|
| «Файлы» (Folder) | Outline | SSH |
| «Переподключить» (Refresh) | Outline | RDP |
| «В окне» (Move), подсказка «Переоткрыть RDP-сеанс в отдельном окне» | Outline | RDP |
| «Весь экран» (Server), доступна при подключении | Outline | RDP |
| «Новый сеанс этого сервера» (Plus) | Quiet | все |
| «Закрыть» | Quiet, красная | все |

### 3.4 Область сеанса
Без сеанса — «Выберите сервер в каталоге, чтобы начать сеанс.» по центру.

### 3.5 Меню сеанса
1. «Переименовать сеанс» — окно «Переименовать сеанс», поле «Метка сеанса», кнопка «Сохранить»; метка уникальна для сервера: «Укажите уникальную метку для сеанса этого сервера.»
2. «Новый сеанс этого сервера»
3. «Файлы (SFTP)» — SSH
4. «Полноэкранный режим RDP» — RDP, при подключении
5. «Открыть в отдельном окне» — RDP
6. «Переподключить» — RDP
7. «Новый сеанс без проброса портов» — только после ошибки проброса (`-o ClearAllForwardings=yes`). Ошибка распознаётся по выводу: `cannot\s*listen\s*to\s*port\s*:` или `could\s*not\s*request\s*local\s*forwarding` без учёта регистра.
8. «Закрыть сеанс»

### 3.6 Поведение
- Закрытие работающего сеанса: «Закрыть SSH-сеанс «X»?» (или RDP), заголовок «Вы уверены?», по умолчанию Нет. Завершённый закрывается без вопроса.
- «Подключиться» возвращает к последнему открытому сеансу этого сервера; «Новый сеанс» всегда открывает новый.
- После выхода SSH в терминал выводится «SSH завершился (код N).», сеанс остаётся в списке с серой точкой.
- Горячие клавиши на странице сеансов: Shift+Esc — к серверам; Ctrl+Tab — предыдущий открытый сеанс; Ctrl+Shift+P — поиск сеанса.

### 3.7 Терминал
- Копировать: Ctrl+Shift+C, Ctrl+Insert, Ctrl+C при выделении. Вставить: Ctrl+Shift+V, Ctrl+V, Shift+Insert, правая кнопка (если удалённая программа не использует мышь). Выделить видимое: Ctrl+Shift+A. Прокрутка: Shift+PgUp/PgDn, колесо — не меньше 3 строк.
- Многострочная вставка спрашивает: «Текст содержит переносы строк. Вставка может сразу выполнить команды. Продолжить?», заголовок «Вставка в терминал». Управляющие последовательности удаляются, переводы строк заменяются на CR.
- Мышь передаётся удалённой программе; Shift — обход. Ввод возвращает к концу прокрутки. Прокрутка назад — 3000 строк.

### 3.8 RDP-сеанс
- Разрешение следует за размером окна (через 450 мс после окончания изменения), в полноэкранном режиме — за размером монитора, в том числе для профиля с фиксированным размером; при выходе возвращается.
- Заглушка после отключения (по центру на #111A27): заголовок «Сеанс завершён» / «Подключение прервано» / «Не удалось подключиться» / «Ошибка RDP-клиента»; строка «имя · адрес» и причина; кнопки «Переподключить» (Primary) и «Закрыть сеанс».
- Если пароль не сохранён — диалог входа (п. 4.3).
- Отдельное окно: заголовок «имя — RDP» (и « (статус)», если не подключено); панель: строка «имя  ·  адрес  ·  статус», «Весь экран» (Primary), «Переподключить», «Отключить» (Quiet, красная).
- Пустой домен на Windows передаётся как «.» (учётная запись на самом сервере); `ДОМЕН\пользователь` в поле пользователя разбирается.

## 4. Диалоги

Общее: по центру родителя, кнопки справа, основная — крайняя справа; Enter — основная, Esc — отмена.

### 4.1 SSH-подключение
Заголовок «Новое подключение» / «Изменить подключение». Поля по порядку: «Псевдоним», «Хост», «Пользователь», «Порт», «Пароль» (скрытый). Под паролем подсказка и флажок «Удалить пароль» (отключает поле):
- «Пароль необязателен. Хранится в Windows.» (на Linux — «в системном хранилище», на macOS — «в Связке ключей»)
- «Пароль сохранён. Пустое поле оставит прежний.»
- «Для нового адреса, порта или пользователя введите пароль заново.»

Строка «Пустые поля используют настройки OpenSSH.». Блок ключей: «Доступные ключи» (найденные в `~/.ssh`) и «Обзор…»; «Выбранные ключи» (список); кнопки «Добавить ключ», «Заменить», «Убрать». Подсказки: «Ключи найдены в папке .ssh.» / «В папке .ssh ключи не найдены. Можно указать файл через «Обзор».» / «Не удалось прочитать папку .ssh. Можно выбрать файл вручную.» Кнопки «Сохранить», «Отмена».

### 4.2 RDP-подключение
Заголовок «Новое RDP-подключение» / «Изменить RDP-подключение». Поля: «Название», «Адрес», «Порт» (3389), «Пользователь», «Домен» (подсказка «Пусто — учётная запись на самом сервере. Для доменной учётной записи укажите имя домена, например CORP.»), «Пароль». Подсказка «Сохранён. Пустое поле — не менять.» / «Необязательно. Хранится в Windows.» и флажок «Удалить пароль». «Ширина экрана», «Высота экрана» (пусто — по размеру окна). Флажки «Общий буфер обмена», «Открывать на весь экран». Кнопки «Сохранить», «Отмена»; у нового профиля ещё «Импорт .rdp…». Ошибки: «Укажите пользователя, чтобы сохранить пароль RDP.», «Укажите числовой порт и размеры экрана.»

### 4.3 Вход RDP
Заголовок «Вход: имя». Адрес (Muted), «Пользователь» (принимает `ДОМЕН\пользователь`), «Пароль», флажок «Сохранить пароль в Windows» (на Linux/macOS — в системном хранилище / Связке ключей), кнопки «Подключиться», «Отмена».

### 4.4 Вкладка
«Новая вкладка» / «Переименовать вкладку»: полужирная подпись «Название вкладки», поле (до 32), кнопки «Создать» / «Сохранить» и «Отмена».

### 4.5 Выбор сервера
«Новый сеанс»: переключатель SSH/RDP (начинается с текущего протокола каталога), поиск «Найти сервер», список (точка цвета вкладки, имя, «адрес  ·  вкладка»), строка статуса «Серверов: N» / «Серверы не найдены.» / «Сохранённых серверов пока нет.», кнопки «Подключиться», «Отмена». Стрелки в поиске двигают выбор, Enter или двойной клик — подключиться. Всегда открывает новый сеанс.

### 4.6 Резервные копии
Типы: «Защищённая копия (*.sshbackup)» и «Архив ZIP (*.zip)», имя по умолчанию `ssh-manager-ГГГГММДД-ЧЧММСС`. Экспорт защищённой: окно «Защита резервной копии», поля «Пароль», «Повторите пароль», примечание о паролях. Импорт: «Пароль резервной копии», поле «Пароль», «Продолжить». Ошибки: «Введите пароль.» / «Пароли не совпадают.» Перед импортом — сводка: новые и заменяемые файлы, новые и заменяемые пароли SSH и RDP, первые 7 заменяемых путей и «И ещё N». Если менять нечего — «Данные из резервной копии уже восстановлены.»

### 4.7 Обновление
«Обновление SSH Manager»: «Доступна версия X» (шрифт заголовка), «У вас версия Y», ссылка «Что нового на GitHub», кнопки «Скачать обновление» (Primary) и «Позже». Если версия актуальна — «Установлена актуальная версия X.» Перед установкой — «Установить версию X и перезапустить SSH Manager?» и, при открытых сеансах, «Открытые сеансы SSH и окна SFTP будут закрыты.»

macOS: если заменить приложение не удалось, окно называет причину и оставляет проверенный DMG. Кнопки: «Закрыть», «Открыть DMG», «Повторить» (Primary); если замену запретила защита macOS «Управление приложениями» — ещё «Открыть настройки» (раздел «Конфиденциальность и безопасность → Управление приложениями»). «Повторить» использует уже скачанный файл. Приложение, запущенное не из папки «Программы» (из DMG или из папки загрузок), просит сначала перенести его туда.

### 4.8 Файлы (SFTP)
Windows и macOS: панель «Файлы» открывается в рабочей области главного окна (§3.2.1), без своего окна, с кнопкой «Закрыть». Остальное — как ниже.

Окно «Файлы — псевдоним · адрес», 1090×620; одно окно на сервер. Шапка «Файлы · псевдоним» и «Переподключить». Две панели: «Компьютер» (домашняя папка) и адрес сервера. В панели: заголовок, поле пути (Enter — перейти), кнопки «Вверх», «Обновить» и «Выбрать папку…» (слева) или «Новая папка» (справа), таблица «Имя» / «Размер» / «Изменён» (`дд.ММ.гг ЧЧ:мм`), папки сначала. Строка действий: «На сервер» (Primary), «На компьютер», «Отменить», ход передачи «имя · сделано / всего». Меню сервера: «Скачать», «Переименовать», «Удалить». Конфликт «Файл уже существует»: «Заменить», «Сохранить оба» (по умолчанию), «Пропустить», «Отмена». Закрытие при передаче — «Прервать передачу и закрыть окно?»

### 7.1 Особенности Windows

- «Быстрое подключение» стоит справа от переключателя SSH/RDP (в строке инструментов не хватает места при ширине 800), `Ctrl+L` переводит в него фокус.
- Избранный сервер вместо значка сервера отмечен янтарной звездой в первом столбце. Вкладка «Избранное» не имеет меню и делит порядок сортировки со «Все серверы».
- «Настройки» — кнопка Quiet со значком шестерёнки. В узком окне «Настройки», а затем переключатель темы показывают только значок.
- Строка «Сеанс SSH завершён (код N)» стоит под терминалом. При автопереподключении: «Соединение прервано · повтор через 5 с (попытка N из 3)».
- «Команды» — выпадающее меню: команды (подсказка — текст команды), «Во все открытые сеансы» (флажок), «Добавить…», «Удалить» › команда.
- RDP «Дополнительно» раскрывается кнопкой. Встроенный клиент подключает целые диски, поэтому из списка папок берутся буквы дисков. «Все мониторы (в клиенте Windows)» открывает профиль в mstsc.

## 8. VNC

Третий протокол рядом с SSH и RDP. Профили, сеансы, избранное, недавние, быстрое подключение, резервные копии и импорт устроены как у RDP.

| Что | Значение |
|---|---|
| Вкладка протокола | третья кнопка «VNC» после «SSH» и «RDP», значок Server |
| Заголовок каталога | «VNC-подключения» |
| Столбцы таблицы | «Название», «Адрес», «Пользователь», «Порт», «Вкладка», «Рабочий стол» (как у RDP) |
| Порт по умолчанию | 5900 |
| Пустой список | «Добавьте VNC-подключение.» |
| Окно профиля | «Новое VNC-подключение» / «Изменить VNC-подключение» |
| Поля | «Название», «Адрес», «Порт», «Пользователь» (необязательно, для серверов с логином), «Пароль» + подсказка «Необязательно. Хранится в …» / «Сохранён. Пустое поле — не менять.» + флажок «Удалить пароль»; «Через SSH-сервер» (выпадающий список: «Напрямую» + псевдонимы SSH); «Масштаб» (`По размеру окна` / `Исходный размер`); флажки «Только просмотр», «Общий буфер обмена», «Открывать на весь экран» |
| Подсказка к паролю | «VNC-пароль: учитываются первые 8 символов.» |
| Файлы | «Файлы» в сеансе открывает файловое окно. При подтверждённой поддержке TightVNC 2.x в Windows оно передаёт файлы напрямую через VNC. В остальных случаях используется поле «SSH-профиль для файлов». Если подходящий способ недоступен, окно показывает причину и оставляет рабочий стол открытым. |
| Меню строки | «Подключиться», «Новый сеанс», «Открыть в отдельном окне», «Изменить», «В избранное»/«Убрать из избранного», «Переместить во вкладку», «Удалить» |
| Подтверждение удаления | «Удалить VNC-подключение «Имя»?» |
| Сеанс: строка деталей | `VNC  ·  host:port  ·  вкладка  ·  статус` (+ `  ·  через alias` при туннеле) |
| Статусы | «подключение», «подключён», «отключён», «отключён (ошибка)» |

| Ошибки | «Неверный пароль VNC.», «Сервер VNC не поддерживает доступный способ входа.», «Не удалось открыть SSH-туннель: …», «Сервер VNC закрыл соединение.» |
| Быстрое подключение | `vnc://[user@]host[:port]` |
| Ключи | избранное/недавние `vnc:<id>`; ключ сеанса `VNC:<id>` |

Хранение (только добавляемые поля, старые версии их пропускают):
- `tabs.xml` (Windows, macOS): элемент `<vnc id="32 hex" name="" host="" port="5900" user="" group="<id вкладки>" scale="fit|native" viewOnly="1" clipboard="1" fullScreen="1" via="<ssh alias>" filesVia="<ssh alias>"/>`; атрибут корня `vncSort` (как `rdpSort`), у вкладки `vncSort`.
- `settings.json` (Linux): `"vnc": [{"id","name","host","port","user","group","scale","view_only","clipboard","fullscreen","via","files_via"}]`, сортировка `"sort"` с ключом протокола `vnc` (как `rdp`).
- Пароль: Windows Credential Manager `SSH Manager/VNC/<id>`; Linux Secret Service, ключ `sha256("vnc\n"+id)` (как `DesktopProfile.secret` в `linux/ssh_manager/rdp.py`); macOS Связка ключей, аккаунт `"vnc\n" + id`.
- Резервная копия: `app/passwords/vnc-<id>` (рядом с `rdp-<id>`), только в защищённом архиве. Сводка защищённого архива включает пароли VNC. Windows показывает сохранённые, новые, заменяемые и восстановленные пароли VNC. На macOS в сводке импорта есть строки «VNC-паролей» и количество восстановленных паролей VNC.

Подсказка быстрого подключения на всех платформах — «Быстрое подключение: user@host, rdp:// или vnc://».

На macOS VNC всегда открывается в отдельном окне. Статус системного клиента — «открыт в приложении „Общий экран“». При закрытии его окна карточка сеанса остаётся в SSH Manager. Для завершения сеанса и его SSH-туннеля используйте «Закрыть сеанс». Масштаб, буфер обмена и полноэкранный режим системного клиента настраиваются в его окне. Для принудительного «Только просмотр» нужен TigerVNC. Сохранённый пароль для «Общего экрана» можно вставить из буфера обмена в течение минуты.

Платформы: Windows — встроенный клиент RFB внутри окна (как RDP); Linux — виджет gtk-vnc внутри окна (X11 и Wayland); macOS — TigerVNC Viewer, если установлен, иначе приложение «Общий экран» (`vnc://`). Встроенные клиенты поддерживают вход без пароля и классический VNC-пароль; Apple ARD (тип 30) и VeNCrypt (тип 19) в первой версии не поддерживаются.


Общий буфер обмена VNC передаёт обычный текст в обе стороны. Windows согласует Extended Clipboard для UTF-8, если сервер его поддерживает. Для базового RFB применяется Latin-1. В Linux gtk-vnc 1.6 и совместимые сборки синхронизируют UTF-8 при поддержке Extended Clipboard сервером. Ранние версии используют базовый обмен. В macOS возможности буфера зависят от выбранного клиента. «Только просмотр» отключает обмен в SSH Manager.
