# SSH Manager для Windows

Поддерживаются Windows 10 версии 1809 и новее и Windows 11. [Скачать установщик или переносную версию](../README.md#скачать).

## Подключения

В каталоге нажмите **Добавить сервер** и заполните поля. Псевдоним — это имя, под которым вы увидите сервер в списке. Укажите адрес, SSH-пользователя и порт. Пустые поля используют остальные настройки OpenSSH. Ключ можно выбрать из папки `.ssh` или указать его расположение кнопкой **Обзор**.

- **Подключиться** открывает терминал. Если сеанс с этим сервером уже открыт, **К сеансу** возвращает в последний использованный.
- **Новый сеанс** позволяет открыть ещё один терминал. В меню сервера также есть пункт **Открыть в Windows Terminal**.
- Если локальный порт для проброса уже занят, в меню сеанса появится команда **Новый сеанс без проброса портов**.

### Сохранённые пароли

Пароли хранятся в Диспетчере учётных данных Windows. Для автоматического ввода пароля нужен OpenSSH 8.4 или новее. Подтверждение ключа нового сервера и одноразовые коды вводятся вручную.

При редактировании поле **Пароль** можно оставить пустым. Приложение сохранит прежний пароль, если адрес, порт и пользователь остались прежними. Чтобы стереть пароль, отметьте **Удалить пароль**.

## Сеансы и вкладки

В разделе **Сеансы** можно искать открытые терминалы по имени, адресу и группе. Правый клик по сеансу открывает команды для переименования, создания ещё одного сеанса и закрытия.

- `Ctrl+Tab` переключает два последних сеанса.
- `Shift+Esc` возвращает к списку серверов и оставляет сеанс открытым. `Esc` передаёт Escape в терминал.
- `Ctrl+Shift+P` фокусирует поиск.
- `Ctrl+Shift+C` и `Ctrl+Insert` копируют выделение. `Ctrl+C` копирует выделенный текст, а без выделения прерывает удалённую команду.
- `Ctrl+V`, `Ctrl+Shift+V`, `Shift+Insert` и правая кнопка мыши вставляют текст. `Ctrl+Shift+A` выделяет видимую часть терминала. Для вставки текста с переносами строк потребуется подтверждение.
- Колесо мыши и `Shift+Page Up/Down` прокручивают вывод.

Создайте вкладку через **Новая вкладка**, затем в меню сервера выберите **Переместить во вкладку**. Сервер можно добавить в одну пользовательскую вкладку. Он также будет виден в разделе **Все серверы**. В меню вкладки можно изменить её имя, цвет и порядок или назначить её стартовой. Порядок также меняется перетаскиванием.

Кнопка **Тёмная тема** меняет оформление каталога и сеансов. Выбор сохраняется после перезапуска и при экспорте настроек.

При закрытии окна приложение остаётся в области уведомлений и сохраняет сеансы. Чтобы вернуть окно, нажмите на значок SSH Manager или запустите приложение снова. Команда **Выход** в меню значка завершает встроенные сеансы.

## Передача файлов

Нажмите **Файлы** в каталоге или в разделе **Сеансы**. Откройте папку двойным щелчком или введите путь. Выделите файлы или папки и нажмите **На сервер** или **На компьютер**. Файлы из Проводника или левой панели можно перетащить на правую панель.

Во время передачи виден прогресс, и очередь можно отменить. При совпадении имён можно сохранить оба файла, пропустить файл или заменить его. На стороне сервера можно создавать папки, переименовывать элементы и удалять файлы или пустые папки. При копировании папок символические ссылки пропускаются.

SFTP открывает отдельное подключение с настройками того же профиля OpenSSH и сохранённым паролем. Проброс портов для этого подключения отключён.

## Где лежат настройки

- `%USERPROFILE%\.ssh\config` — подключения в формате OpenSSH и кодировке UTF‑8. Каталог показывает секции `Host` с одним псевдонимом. Секции с несколькими псевдонимами, шаблоны, `Match` и файлы `Include` редактируются вручную.
- `%USERPROFILE%\.ssh\config.bak` — предыдущая версия конфига, создаваемая перед записью. Для ключей в конфиге хранятся пути к файлам.
- `%LOCALAPPDATA%\SSH Manager\tabs.xml` — тема и вкладки. Серверы привязаны к вкладкам по псевдонимам из конфига.

## Резервные копии

Нажмите **Резервные копии**, чтобы сохранить или восстановить конфиг, вкладки и SSH-ключи.

- Защищённый архив **.sshbackup** открывается по паролю. Он может включать сохранённые SSH-пароли. При импорте они записываются в Диспетчер учётных данных Windows.
- Обычный **ZIP** содержит конфиг, вкладки и ключи в открытом виде.

В копию попадают доступные локальные ключи, файлы по поддерживаемым путям `IdentityFile` и `CertificateFile` и файлы `Include` с буквальными путями или шаблонами `*` и `?` в имени. Пути к сохранённым файлам переписываются относительно `~/.ssh`. После экспорта приложение показывает, сколько ссылок было пропущено. Файлы `authorized_keys` и `known_hosts` из копии исключаются.

Перед импортом приложение показывает, какие файлы будут заменены. Предыдущие версии сохраняются в папках `.ssh-manager-restore` внутри `.ssh` и папки настроек SSH Manager.

## Обновления

Начиная с версии 1.8.0 приложение проверяет наличие обновлений при запуске. Проверку можно запустить кнопкой **Обновления**. После скачивания приложение сверяет контрольную сумму SHA‑256 с GitHub Releases и запрашивает подтверждение установки и перезапуска. Версия MSI обновляется через Windows Installer. Переносная версия заменяет свой EXE.
